A focused workflow

Use your PDFs as a source.

Start small, inspect the result, then process the rest of the book. The local web app makes it easy to monitor extraction and review flagged items.

01 / PREVIEW

Check a page range

Use inspect to preview figure detection on a few pages before spending model usage.

02 / EXTRACT

Run and resume

Extract a chapter or full book. Cached page results let you safely resume the same run later.

03 / REVIEW

Verify the output

Browse questions, diagrams and solutions in the local UI. Fix flagged pages and rebuild the JSON.

Quick start

Run it on your machine.

Install the project, sign in to whichever supported CLI you use, then launch the web workspace at 127.0.0.1:8000.

Python 3.10+Claude CLI and/or Codex CLINo API keys
# Install
uv venv .venv
uv pip install --python .venv/bin/python -e ".[dev]"

# Sign in to one or both
claude       # then /login
codex login

# Start the local review workspace
.venv/bin/python -m pyqforge ui

# Or run a small extraction directly
.venv/bin/python -m pyqforge inspect book.pdf --pages 1-5
.venv/bin/python -m pyqforge extract book.pdf --out out --pages 1-5 --engine auto --verify
